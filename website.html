제작 범위

필요한 범위만큼 선택하세요.

제작비와 기간은 페이지·콘텐츠·기능 범위에 따라 달라집니다. 확정 금액은 상담에서 안내합니다.

Basic

주요 페이지 5~8개. 기본 정보구조 설계와 인터뷰 기반 원고 정리, 맞춤형 메인 디자인과 반응형 구현.

Premium

주요 페이지 10~15개. 고객·업종 조사와 콘텐츠 기획, 주요 원고 작성, 운영형 콘텐츠 구조까지.

Enterprise

20페이지 이상 또는 복합 구조. 심층 조사와 콘텐츠 전략, 다국어와 외부 연동, 집중 안정화까지.
